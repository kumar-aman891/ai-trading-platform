# Backtest Skill

Accept a versioned strategy definition, symbol universe, date range, timeframe, capital, fees, slippage model, and execution assumptions.

Return:
- equity curve
- CAGR/annualized return
- volatility
- max drawdown
- Sharpe/Sortino where meaningful
- win rate
- profit factor
- expectancy
- turnover
- exposure
- largest loss
- recovery factor
- trade distribution
- regime breakdown
- out-of-sample results
- sensitivity analysis
- known limitations
