# Frontend — deferred

This directory holds the target structure from the approved Phase 1 plan
(`app/`, `routes/`, `components/`, `api/`, `auth/`, `lib/`), created empty.

Node.js/npm are not installed in this environment and were not part of the
Step 2 checklist (`package.json`, Vite, TypeScript, and Tailwind
configuration). The frontend shell itself is Phase 1 Step 18. Configuring the
npm/Vite toolchain requires Node.js to be installed first — see the
implementation report for this step.

The `routes/live/` route, when it lands in Step 18, will render a static
"not implemented in this build" notice only. It will not contain an order
form, an arm control, or a live API client.
